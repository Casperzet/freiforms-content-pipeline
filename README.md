# FreiForms content pipeline

Assets for the FreiForms (@frei_forms) daily reel job and website.

- `animation/` Three.js scene renderer (vendored `node_modules/three`, no npm install needed), story content, fonts
- `voice/` voice/TTS scripts
- `marketing/`, `styleframes/` copy and style references
- `site-generator/` Python static-site generator (`content.py`, `content2.py`, `build.py`) + built `site/`
- `instagram/` profile texts and avatar

Brand "Quiet Premium": #0D0E12 bg, #15171D panel, #F3F1EC ink, #9A9FAE muted, #FF8A6E accent.
